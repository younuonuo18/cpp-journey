## 1.4 作业 · 国内外 AI 编程助手对比表（2026-09-30 核对）

> 六家的**定位 / 是否国产**是稳定信息；**免费额度会变**。下表填的是核对到的最新情况，写「以官网为准」的地方就是我没能确认到确切数字的——宁可留白也不编。

| 工具 | 定位 | 免费额度 | 是否国产 | 适用场景 |
|---|---|---|---|---|
| **GitHub Copilot** | IDE 内补全 + 对话（VS / VS Code 官方集成） | **Free：对话 200 次/月 · 补全 2000 次/月**（本机实测：ChatQuota 200、CompletionsQuota 2000，每月 22 日前后重置） | 否（微软 / GitHub） | **本学期主力**：VS 2026 里已激活可用，直接跟教材走 |
| Cursor | 以 AI 为核心的独立 IDE（VS Code 分支） | 免费 Hobby 档额度有限，超出需订阅 Pro / Pro+ / Ultra | 否 | 想"整项目改代码"时再试；与 VS 功能重复，现在不必 |
| 通义灵码 → **Qoder CN**（已改名） | 阿里云 AI 编程助手（IDE 插件 + 独立 IDE） | 免费社区版 + Credits 额度（2026 年调整过计费） | 是（阿里云） | 国内网络顺畅、中文友好；VS Code / JetBrains 用户 |
| 文心快码 Comate | 百度 AI 编程助手（IDE 插件） | 有免费档；确切额度以官网为准 | 是（百度） | 备选，与上一行同类 |
| CodeGeeX | 智谱 AI 编程助手（IDE 插件） | 个人版免费 | 是（智谱） | 免费补全的备用选项 |
| Trae | 字节跳动 AI IDE | **2026 年已从"按次数"改为"按 Token"计费**；免费额度以官网为准 | 是（字节） | 想体验"国产 Cursor"时试 |

**这张表真正要记住的 3 件事**

1. **分类比背名字有用**：补全型 / 对话型 / Agent 型 / 独立 IDE。本学期你只需要"IDE 内补全 + 对话"这一类，其余都不用碰。
2. **数字会过期，会查官网比记得住重要**：做这张表就抓到 3 个变化（灵码改名、Trae 改计费、额度口径不统一）。教材 2026-09 样书上写的名字，现在已经对不上了。
3. **工具不是瓶颈**：你已经有 Copilot Free 且实测可用，这一个就是主力——别在"选工具"上再花时间。决定产出的是**问法**（第 10 章）。
