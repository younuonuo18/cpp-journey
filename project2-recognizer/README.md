## 三、编译与运行

### 方式一：Visual Studio 2026（MSVC，本机实测环境）

1. 打开解决方案 `src/recognizer.slnx`；选择 `learn` 项目（本人实现）；
2. 环境：`Debug | x64`；生成：`Ctrl+Shift+B`；运行：`Ctrl+F5`；
3. **`learn.exe` 是无参数运行的菜单程序**，按提示输入编号与文件路径：

```
 1 读取带标签数据集（CSV，6 列）      4 加载模型文件（TEACHMODEL_V1）
 2 读取待预测数据集（CSV，5 列）      5 保存模型文件
 3 独立校验已加载的数据              6 预测全部样本
 7 一致性自检（保存→重新加载→比较概率） 8 显示安全声明   0 退出
```

建议演示顺序：`4`（`..\data\reference_model.txt`）→ `1`（`..\data\train.csv`）→ `6` →
`2`（`..\data\predict.csv`）→ `6` → `5`（`..\report\model_saved.txt`）→ `4`（同一文件）→ `7` → `8` → `0`。

本机实测信息：

| 项 | 值 |
|---|---|
| 操作系统 | Windows 11（64 位） |
| 编译器 | MSVC（Visual Studio Community 2026，工具集 14.51.36231，C 标准 C11） |
| 编译配置 | Debug / x64 |
| 生成命令 | `MSBuild learn.vcxproj /p:Configuration=Debug /p:Platform=x64` |

> 注意：源码须保存为 **UTF-8 带签名（BOM）**，否则 MSVC 会按 GBK 解析中文注释并报 `C2001/C4819`。

### 方式二：gcc + 教师 Makefile（仅参考实现）

```bash
cd src
make          # 等价于 gcc -std=c11 -O2 -Wall -Wextra -pedantic recognizer.c -lm -o recognizer
./recognizer
```

> `recognizer_starter.c` 是**故意未完成的骨架**（TODO 直接返回"未实现"），不是成品，未作改动。

## 四、输入数据格式

```text
file_size,string_count,entropy,byte_00_ratio,byte_ff_ratio,label
```

- 列顺序**固定**；预测数据 `predict.csv` **没有** `label` 列（5 列）；
- `file_size ≥ 0`；`string_count` 为非负整数；`entropy ∈ [0,8]`；两个比例 `∈ [0,1]`；`label ∈ {0,1}`；
- 返回码约定（12 类）：`0` 成功、`2` 打不开、`3` 空数据、`4` 表头不符、`5` 字段数不符、`6` 空字段/空行、
  `7` 非数值或非有限值、`8` 越界或非整数、`9` 非法标签、`10` 超过 512 条、`11` 模型文件损坏、`12` 数据或模型未就绪。
