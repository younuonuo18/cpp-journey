## 一、项目背景与安全边界

用文件大小、信息熵、可见字符串数量、0x00 与 0xFF 字节占比这 **5 个静态特征**，配合一个**逻辑回归教学模型**，判断样本是「良性(0)」还是「可疑(1)」。

**安全边界（必须在报告与程序里都写明）**

- 只使用教师提供或人工构造的 **CSV 静态特征数值**；
- **不**下载、**不**运行、**不**传播任何真实恶意代码；
- **不**开发任何绕过检测的功能；
- 程序输出（良性/可疑）只是**教学模型的类别预测**，**不构成**真实软件的安全判定。

## 二、需求清单（输入 → 处理 → 输出）

### 2.1 输入

| 输入 | 格式 | 说明 |
|---|---|---|
| 带标签数据集 | CSV，6 列 | 表头固定为 `file_size,string_count,entropy,byte_00_ratio,byte_ff_ratio,label` |
| 待预测数据集 | CSV，5 列 | 同样表头但**没有 label 列** |
| 模型参数文件 | `TEACHMODEL_V1` 文本 | 5 权重 + 偏置 + 5 个 min + 5 个 max（归一化参数） |
| 用户操作 | 命令行菜单 | 选择功能、输入文件路径 |

### 2.2 处理

1. **读取**：打开文件（失败要提示且不崩溃）→ 校验表头 → 逐行解析 6 个字段 → 存入 `Dataset`。
2. **校验**：每一行、每个字段都要检查（见下方"合法性规则"）；任一条不合法 → 整份数据**拒绝加载**并给出明确原因。
3. **容量**：样本数上限 `MAX_SAMPLES = 512`，超出必须拒绝（不能数组越界）。
4. **归一化**：`x[j] = (raw[j] - min[j]) / (max[j] - min[j])`；若某维 `min == max` 则约定归一化结果为 `0`。
5. **预测**：`p = 1 / (1 + exp(-(b + Σ w[j]·x[j])))`，`p ≥ 0.5` 判为 `1`（可疑），否则 `0`（良性）。
6. **模型存取**：保存/加载必须包含**权重、偏置、完整的归一化 min/max**；加载后同一输入的概率必须与保存前一致（**不允许**在预测时重新拟合归一化参数，**不允许**把测试样本重新缩放到 [0,1]）。

### 2.3 输出

- 读取结果摘要：样本条数、每维最小/最大值、标签分布（0/1 各多少条）；
- 预测结果：每条样本的原始 5 特征、概率 `p`（建议保留 6~10 位小数）、类别（`良性`/`可疑`）；
- 错误信息：清晰的失败原因（哪一行、哪一列、什么值、为什么非法）+ **非零退出码**；
- 菜单交互：读取数据 / 校验 / 加载模型 / 预测 / 显示安全声明 / 退出。

### 2.4 合法性规则（"严格解析器"口径）

| 字段 | 规则 | 对应测试用例 |
|---|---|---|
| `file_size` | 有限数值，**≥ 0** | T08 负值 → 拒绝 |
| `string_count` | 有限数值，**≥ 0 且为整数**（不接受 `42.5`） | T14 → 拒绝 |
| `entropy` | 有限数值，**0 ≤ x ≤ 8** | T12（8.5）→ 拒绝 |
| `byte_00_ratio` | 有限数值，**0 ≤ x ≤ 1** | T04（1.3）→ 拒绝 |
| `byte_ff_ratio` | 有限数值，**0 ≤ x ≤ 1** | T05（−0.2）→ 拒绝 |
| `label` | 只能是**整数 0 或 1**（`2`、`-1`、`0.5` 都拒绝） | T03、T18 → 拒绝 |
| 数值格式 | 不接受 `abc`、`nan`、`inf` | T06、T11 → 拒绝 |
| 字段个数 | 每行必须**正好 6 个**（多一个少一个都拒绝） | T07、T13 → 拒绝 |
| 空字段 / 空行 | 拒绝（含只有空格的数据行） | T15、T19 → 拒绝 |
| 表头 | 字段名与**次序**必须与规定完全一致 | T16 → 拒绝 |
| 边界值 | `0`、`1`、`熵=8`、`file_size=0` **必须接受** | T17 → 接受 |
| 字段前后空格 | 数字两边有空格 **必须接受**（应容忍并解析） | T20 → 接受 |

> 说明：上表把"必须接受"的两条也列出来了 —— 一个只会拒绝的程序等于不合格。

## 三、数据结构（沿用教师框架）

```c
#define FEATURE_COUNT 5     /* file_size, string_count, entropy, byte_00_ratio, byte_ff_ratio */
#define MAX_SAMPLES   512

typedef struct { double features[FEATURE_COUNT]; int label; } Sample;
typedef struct { Sample samples[MAX_SAMPLES]; int count; }    Dataset;
typedef struct { double minv[FEATURE_COUNT]; double maxv[FEATURE_COUNT]; } FeatureScaler;
typedef struct { double weights[FEATURE_COUNT]; double bias; int trained; } Model;
```

特征下标（**任务四 A 的坑就在这**）：

| 下标 | 字段 | 合法区间 |
|---|---|---|
| 0 | file_size | ≥ 0 |
| 1 | string_count | ≥ 0 的整数 |
| 2 | entropy | [0, 8] |
| 3 | **byte_00_ratio** | [0, 1] |
| 4 | **byte_ff_ratio** | [0, 1] |

## 四、模块划分与函数接口

| 模块 | 函数 | 职责 | 返回值 |
|---|---|---|---|
| 数据读取 | `int load_dataset(const char *path, Dataset *data)` | 打开文件→校验表头→逐行解析→每个字段合法性检查→容量检查 | 0 成功，非 0 为错误码 |
| 数据校验 | `int validate_dataset(const Dataset *data)` | 对已加载数据做**独立**复检（空集、标签、区间、整数性） | 0 通过 |
| 归一化 | `void fit_scaler(const Dataset *data, FeatureScaler *scaler)` | 只用**训练集**拟合 min/max | 无 |
| 预测 | `double predict_probability(const Model *m, const FeatureScaler *s, const double raw[5])` | 归一化 + sigmoid，返回概率 | 概率（失败返回负值） |
| 模型存取 | `int load_model(const char *path, Model *m, FeatureScaler *s)` | 解析 TEACHMODEL_V1；**权重+偏置+min+max 全读**；格式不全则拒绝 | 0 成功 |
| 模型保存 | `int save_model(const char *path, const Model *m, const FeatureScaler *s)` | 按同样格式写出全部参数 | 0 成功 |
| 摘要输出 | `void print_summary(const Dataset *data)` | 条数、各维 min/max、标签分布 | 无 |
| 预测输出 | `void predict_all(...)` | 逐条打印特征/概率/类别 + 统计 | 无 |
| 菜单 | `int main(void)` | 命令行菜单、错误提示、安全声明 | 退出码 |

**错误码方案（建议，便于填验收表"返回码"一栏）**

| 码 | 含义 | 对应用例 |
|---|---|---|
| 0 | 成功 | — |
| 2 | 文件打开失败 / 文件不存在 | T01 |
| 3 | 空数据集（无数据行） | T02 |
| 4 | 表头字段名或次序不符 | T16 |
| 5 | 字段个数不符（多/少一列） | T07、T13 |
| 6 | 空字段或空白数据行 | T15、T19 |
| 7 | 非数值 / 非有限值（abc、nan） | T06、T11 |
| 8 | 数值越界或类型不符（负值、熵>8、比例越界、计数非整数） | T04、T05、T08、T12、T14 |
| 9 | 非法标签（2、−1、0.5） | T03、T18 |
| 10 | 样本数超过 MAX_SAMPLES | T09 |
| 11 | 模型文件格式不完整/损坏 | T10 |
| 12 | 模型尚未加载就预测 | 任务书用例 7 |

## 五、程序功能流程

```text
启动
 └─ 显示安全声明（仅教学用途）
 └─ 主菜单循环
     ├─ 1 读取带标签 CSV
     │    ├─ 打开文件 ── 失败 → 提示 + 返回码 2
     │    ├─ 读表头 ──── 不符 → 提示 + 返回码 4
     │    ├─ 逐行解析
     │    │    ├─ 空行/空字段 → 6      ├─ 非数值/非有限 → 7
     │    │    ├─ 越界/非整数 → 8      ├─ 非法标签 → 9
     │    │    └─ 字段数不符 → 5       └─ 超过 512 条 → 10
     │    ├─ 全部合法 → 存入 Dataset，打印摘要
     │    └─ 任一条非法 → 整份拒绝，打印"第 N 行第 M 列 = 值，原因"
     ├─ 2 独立校验已加载数据（空集/标签/区间/整数性）
     ├─ 3 加载模型文件（TEACHMODEL_V1：权重+偏置+min+max）
     │    └─ 行数/字段不足 → 提示 + 返回码 11
     ├─ 4 预测
     │    ├─ 未加载数据或模型 → 提示 + 返回码 12
     │    ├─ 归一化（用模型文件里的 min/max，不重新拟合）
     │    └─ sigmoid → 概率 → 阈值 0.5 → 良性/可疑
     ├─ 5 显示安全声明
     └─ 0 退出
```

**分层实现说明**

| 部分 | 来源 |
|---|---|
| `Sample/Dataset/FeatureScaler/Model` 结构体定义、`MAX_SAMPLES`、菜单外壳 | 教师提供框架（`recognizer_starter.c`） |
| CSV 解析、全部字段校验、摘要输出、归一化、sigmoid 预测、模型保存/加载、菜单集成 | **由本人独立实现**（AI 用于解释、审查、补充测试建议） |
| 参考模型参数、教学数据、20 个异常用例、两个错误案例 | 教师提供 |

## 七、待本人核对的 5 个点（今晚 10 分钟）

1. **T09 的口径**：超过 512 条时，是"整份拒绝"还是"读前 512 条 + 警告"？本方案取**整份拒绝**（更严格、更好写"防止数组越界"的说明）。如果你更想保留数据，我们就改成"截断 + 警告"，并在报告里写明理由。
2. **退出码方案**：上表 12 个错误码够不够？要不要再区分"文件不存在"和"无权限"？
3. **预测输出条数**：`predict.csv` 有 20 条，是全部打印，还是只打印前若干条 + 汇总？
4. **中文输出**：程序提示信息用中文（更友好，VS 控制台需确认不乱码），还是中英混合（更保险）？
5. **是否做选做拓展**（训练参数、准确率/精确率/召回率/混淆矩阵）：时间够就做，是加分项。
