# 大语言模型辅助的三个示例提示词（学生需根据自身情况修改）

## 示例一：需求分析

> 我是一名低年级网安专业学生，已学习C语言数组、结构体、函数和文件操作。项目只读取教师提供的CSV静态特征，不接触任何真实恶意程序。请按“输入—检查—分类—输出”拆解需求；先不给完整代码；比较逻辑回归与简单神经网络的学习成本，并说明安全边界。

审查：是否忽略CSV列顺序？是否擅自要求下载/运行真实恶意样本？是否超出已学范围？

## 示例二：函数实现

> 请只给出C语言`validate_dataset`的代码候选方案。`features[5]`依次为file_size、string_count、entropy、byte_00_ratio、byte_ff_ratio，label仅允许0和1。请检查空集、越界、缺字段/非数值、label，并给出至少4个反例；不要生成训练网络或完整项目。

审查：比例字段是下标**3和4**，不是2和3。检查函数是否真的能发现字段缺失（若已被解析器静默跳过，需要先改解析器）。

## 示例三：错误诊断

> 保存逻辑回归权重和偏置后，重新加载模型，同一个原始CSV样本的概率变化。训练时使用了训练集Min-Max归一化。请列出至少3种可能原因和验证实验，优先检查FeatureScaler是否一同持久化。先不要直接重写全部程序。

审查：要区分“重新训练一个新模型”与“加载同一个模型”；用相同的原始输入、相同权重偏置和相同scaler复现实验，然后再修改。

## 个人记录必须写明

原始提示词 → AI建议（简短摘要/截图）→ 学生的验证方法 → 实际观察到的结果 → 采纳/修改/拒绝理由。AI的输出是待验证候选，不是最终答案。
