# 小组与个人提交清单（提交前自行核对）

**小组材料**

- [ ] 完整可编译C源代码与运行说明（说明编译器/参数/操作系统）
- [ ] 程序输入/输出与数据格式、安全边界说明
- [ ] 合法与异常数据的测试记录（至少覆盖任务书列出的8种情形）
- [ ] 使用参考模型保存/加载后，同一输入预测值一致的验证
- [ ] 至少一个典型AI辅助代码错误的完整证据链（复现、定位、修改、回归测试）
- [ ] 实验报告、模块流程图、运行截图、小组分工说明
- [ ] 拓展训练/评价（如果选做）单独标明，并保证测试数据不参加训练或scaler拟合

**每位学生材料**

- [ ] 个人负责模块与核心代码解释
- [ ] 至少3组AI交互记录（需求、编码、测试各1组）
- [ ] 记录本人对AI建议采纳/修改/拒绝与验证理由
- [ ] 反思误报与漏报的潜在影响、教学模型的局限与安全责任

**禁止提交**：真实恶意程序、可执行恶意样本、规避安全检测的功能、未经授权的数据，以及无法解释来源的模型输出。
