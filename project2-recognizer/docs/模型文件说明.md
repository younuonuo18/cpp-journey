# TEACHMODEL_V1 参考模型文件格式

`reference_model.txt`由教师提供的C语言训练参考实现根据`data/train.csv`计算得到，**不包含实际恶意代码分析信息**。

文件按行布局如下（无注释、空格分隔数值）：

```
TEACHMODEL_V1
5
w0 w1 w2 w3 w4
bias
min0 min1 min2 min3 min4
max0 max1 max2 max3 max4
```

特征下标依次对应：

0. `file_size`
1. `string_count`
2. `entropy`
3. `byte_00_ratio`
4. `byte_ff_ratio`

对输入原始特征`raw[j]`，归一化计算为：

`x[j] = (raw[j] - min[j]) / (max[j] - min[j])`

如训练集某一维`min == max`，为避免除零，本实验约定该维归一化结果为0。

教学预测概率为：`sigmoid(bias + sum(w[j] * x[j]))`；阈值`0.5`，概率不小于该值时输出`1`（可疑教学标签），否则输出`0`。

**关键要求：** 模型文件应包含权重、偏置和训练阶段生成的完整scaler；重新加载不得在测试集或单条预测输入上重新拟合归一化参数。

**注意：** 归一化后的测试值可能小于0或大于1（因测试样本超出训练集范围），不要擅自重新缩放测试样本以强制限定在[0,1]。
